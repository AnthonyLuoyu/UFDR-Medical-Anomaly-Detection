# UFDR: Uncertainty-Guided Feature Distribution Refinement for Unsupervised Medical Image Anomaly Detection

Official implementation of **UFDR**, a framework for unsupervised medical image anomaly detection.

## Overview

UFDR is designed for unsupervised medical anomaly detection under a normal-only training setting.

The framework mainly contains:

- **PUCL**: Pair-wise Uncertainty-guided Curriculum Learning
- **TGDR**: Training-guided Decoder Regularization

UFDR is evaluated on seven medical anomaly detection datasets across multiple imaging modalities.
